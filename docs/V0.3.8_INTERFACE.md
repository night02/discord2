# Veylor V0.3.8 — interface desktop e identidade visual

Esta versão adota a logo azul/ciano em PNG aprovada para a Veylor, sem substituir
o conteúdo de usuários e sem alterar a API ou o banco. A V0.3.7 permanece disponível
em GitHub Releases.

## O que mudou

- Identidade própria: a mesma logo na tela de entrada, barra de servidores, executável
  Windows, instalador Inno Setup e launcher Android de teste.
- Estrutura familiar de comunicador: lista de servidores, DMs/canais à esquerda,
  mensagens no centro e painel de membros opcional à direita em desktops largos.
- Melhor contraste, itens selecionados, botões com tooltip, estado de conexão,
  navegação adaptativa via drawer em telas menores.
- Pesquisa **local nas mensagens já carregadas**; não promete pesquisa no servidor.
- Envio real via API existente; reconexão, convites, permissões de membros e
  atualização segura permanecem conectados aos métodos anteriores.
- Rolagem ao fim das mensagens ao enviar e trocar de canal/DM.
- Exibição da versão real do pacote (não mais texto fixo V0.3.4).
- Nenhum botão de chamada falsa: a ativação real da mídia ainda depende de
  configurar LiveKit no servidor e integrar cliente de áudio/vídeo.

## Ícones

Arquivo fonte: `apps/client/assets/veylor_logo.png`.
Script Windows: `python tool/prepare_brand_icon.py` após `flutter create`.
O script gera `windows/runner/resources/app_icon.ico`, usado no `veylor.exe`
e no `SetupIconFile` do instalador.
Script Android: `python3 tool/prepare_brand_android.py` após `flutter create`,
substituindo `mipmap-*/ic_launcher.png` por PNG da marca.
O Flutter utiliza o asset no login e na navegação.

## Testes e publicação

Os PRs devem passar Flutter analyze/test, SQLite/PostgreSQL, saúde hospedada
e builds de Windows, Linux e Android. O smoke Windows continua verificando
instalação, integridade, rollback e desinstalação antes de permitir release.
A publicação automática só ocorre para o mesmo commit de `main` depois
de toda a CI passar. Não altere a V0.3.7 nem anuncie assinatura Windows
sem certificado real.

## Limites

A interface é **inspirada na organização** de apps de comunicação e mantém
identidade visual própria da Veylor. A infraestrutura atual não oferece
chamada LiveKit funcional; nenhum controle simula esse recurso.
A pesquisa abrange somente mensagens carregadas. Testes manuais de
navegação e usabilidade em Windows real continuam recomendados antes
de promover a beta a uma versão estável.
